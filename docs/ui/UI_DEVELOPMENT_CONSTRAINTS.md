# 上帝的力量 HTML 项目：UI 开发长期约束

1. 本项目是纯桌面端课堂竞技程序，不要求移动端适配。
2. 标准设计分辨率为 1920×1080，最低支持 1366×768。
3. 保留现有青绿珊瑚扁平视觉体系。
4. 始终保持离线单文件 HTML 发布能力。
5. UI 修改不能擅自改变积分、道具、回合和归档规则。
6. 不允许通过不断覆盖旧函数和追加 CSS 补丁实现新功能。
7. 新页面和新组件必须复用已有设计变量。
8. 动画必须可以中断、跳过和清理，不得控制业务结果。
9. 每次 UI 修改必须使用真实浏览器截图验证。
10. 必须测试正常、空状态、大量数据及边界状态。
11. 每次修复应补充相应的自动化回归测试。
12. 重大 UI 修改必须使用独立分支和可回滚提交。
13. 不得以生成截图、通过语法检查代替完整功能验收。
14. 不得删除或重置真实课堂数据。
15. 每次完成开发后更新维护列表，记录已解决问题和遗留事项。

本轮补充：仅使用 Chromium；不得执行 CircleCI 相关操作。重要比赛布局必须先记录用户真实配置或明确标注合成配置，以相同数据进行 14 组前后 DOM 对比。

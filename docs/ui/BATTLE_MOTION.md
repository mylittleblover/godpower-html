# 比赛动画与按钮音效规范

本轮基线 bf627e4f79ee9fdfe3e1d8ca231be751b1839dc3。只修改表现和声音入口，不修改计分、排名、All In、26 道具参数或存档语义。

## 连贯时序

- 全局道具抽取：遮层 380ms 渐入；图标、名称及提示各 400ms、按 60ms 间隔跟进；原抽取滚动仍 1500ms，结果停留 900ms，最后 620ms 渐出。遮层不会缩放或移动卡片。CSS reveal 的填充动画必须在渐出前清除，否则会把 opacity 固定为 1，吞掉退出过渡。
- 发动、受击、防御与治疗：BattleMotion 独立层统一 1700ms，最后约 600ms 用于淡出。按道具形状区分龟壳、火、冰、闪电、炸弹、喇叭、香蕉、锤子、回旋镖、幽灵、墨雾、冲刺与增益；原图标及名称保留。
- 持续效果：原星星、巨大蘑菇、强化与冰冻光环采用 2.8s 透明度呼吸。取消重复的卡片级巨大/冰冻滤镜动画，保留原状态颜色和标识。状态到期、队列晋升有短提示，不改变状态计算。
- 道具分数：约 980ms 等待发动表现，1050ms 分差提示，920ms 旧值/新值交接。普通数字插值延长至 950ms。实际 score 仍立即改变，仅 displayScore 延迟。

## 布局与生命周期

不改变 groupList、卡片高度/宽度、间距、垫片或底栏。临时效果用绝对定位且 pointer-events:none；只移动视觉层，不与排名 FLIP 争用卡片 transform。角标放左下，避免覆盖右侧答题按钮。

分数滚动继承小组颜色，幽灵数字以右侧为共同锚点。禁止把 getBoundingClientRect 的缩放像素直接赋给 min-width/min-height；这会在页面缩放时产生跳位。重绘后根据同一会话的已过时间重建数字层。

BattleMotion 按小组及事件类型管理有限会话，重绘挂回已有抽取遮层、恢复未结束的反馈。后来的同类事件替换前一会话。离页、隐藏、撤销、偏好变化及跳过清理节点和计时器。跳过还确认当前已提交的状态快照，防止稍后重绘把旧状态再次当成新事件；下一次真实状态变化仍正常播放。

减少动态效果和关闭动画时不播放非必要层；简洁模式取消复杂运动。动画结束不结算积分或消耗库存。

## 按钮独立声音

新增 22 个稳定 ui_button_* 槽：导航、打开、关闭、展开、选答案、All In、开始、判定、下一题、撤销入口、抽道具、用道具、点名开始/停止、快捷加/扣分、确认、取消、上传、导出、危险操作、设置分类。

设置中的基础声音进一步分为七类：导航与窗口、答题与回合、道具与课堂工具、设置与数据、计分与比赛结果、通用按钮默认音效、点名过程与结果。保留公共道具事件和 26 个道具独立发动区，共 63 个活动槽。

所有新槽复用原候选音效上传、随机选一、移除、还原及音频包。未上传独立声音时继承旧 ui_click 自定义文件；没有旧文件时使用不同音高的短默认音。同一点击旧 ui_click 调用仍去重，按钮声沿用独立开关/音量及单声部，不叠加多个长点击文件。操作入口声音与成功/失败结果声音分开；点击声不代表业务成功。

## 维护与验收

`npm run build && npm run check && npm test && npm run test:battle-motion`。

配合 `node tests/e2e/desktop-interactions.mjs` 验证旧窗口及取消接口，`node tests/e2e/rules.mjs` 验证 26 道具行为，`battle-layout.mjs` 比较 14 小组几何。测试截图及阶段哈希见 reports/BATTLE_MOTION_ACCEPTANCE.md。实际听感需人工，不能用 BufferSource 路径断言替代耳听。

试听按钮标记 data-sound-preview，跳过自动点击反馈，直接播放选定声音；日常按钮声关闭不阻止试听，试听仍遵循点击音量。避免把用于抑制重复点击的门禁同时用于禁止设置预览。

抽取结果提交后立即在遮层下刷新库存。淡出开始时同步恢复卡片内容亮度，保留遮层居中样式到真正移除；避免结束重绘时才让道具图标突然出现。重绘恢复时同时恢复 item-draw-spinning 与淡出阶段标志。举手奖励的单组抽取和结果面板同样使用 380ms 渐入。

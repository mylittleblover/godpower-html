# 六槽赋分、抽取与全屏反馈规范

基线：9d449780731f6ae78ef9f49dc6475a16fe3adc04。保留比赛与道具规则、随机赢家、防重复、计分及撤销语义。

## 统一赋分

抽取、举手奖励、小组赋分、独立积分窗口、按人赋分五个入口共用六个槽位。默认 +1、+2、+5、−1、−2、−5；在“设置 → 课堂与比赛规则 → 六个快捷赋分槽位”修改。六项均为非零安全整数，允许负数，非法/空值不覆盖已保存配置。原输入框和原命令保留，举手增加手动输入。

`ClassroomFeedback.slotMarkup` 是唯一快捷按钮渲染器；按钮调用原命令。配置改变同步现有窗口及以后新打开的窗口，未生成新函数覆盖链。

## 抽取

业务仍在开始时决定赢家。新展示层只顺序循环候选名单，不消耗随机数；双层模式遵循预选小组范围。运行阶段使用真正的纵向连续 WAAPI 转轮，每行约 100ms。停止时读取实际位移和小数相位，接上约 1 秒非线性减速，最终行使用原命令确定的赢家和原彩色学号组件。

关闭窗口、切换模式或页面时移除展示条并恢复原名称可见性。动画完成检查 generation 和同一赢家，不能让旧回调打开新结果。奖励按钮在减速期间继续禁用。

## 全屏演出

设置位置：“动画与特效 → 全屏课堂特效”。抽中与自由赋分可分别开启。两种已实现风格：极光聚焦（光环、入场和流光粒子）与星火绽放（放射条状粒子、点阵光环）。时长 1.2 / 1.8 / 2.6 / 3.6 秒，默认 1.8 秒。

抽中显示真实姓名、小组和学号；小组模式显示真实小组名。实际加分采用绿色，扣分采用红色，展示实际分值。批量赋分展示实际合计；安全整数合计之外不播放数值演出，不影响原有逐组积分。

全屏采用原生 dialog/top layer 与暗色模糊遮罩，接入已有弹窗栈、关闭按钮、焦点和 280ms 退出动画。对应用缩放单独抵消，确保全屏几何不随 .8/1/1.25 页面缩放溢出。现有可见 toast 重新置于顶层。可点击继续课堂或按 Escape 跳过；跳过只结束表现，不重复或撤销业务结果。

关闭非必要动效或尊重系统减少动态效果时不播放全屏演出；简洁模式保留简短姓名展示，减少粒子。页面隐藏、状态恢复、下一次操作或设置变化清理旧演出和定时器。只保留一个演出，不积压队列。

## 按钮音效

所有可操作 button、summary、role=button 和按钮型 input 通过一次事件委托接入原 ui_click 槽。动态创建和键盘触发同样接入；禁用/inert 控件不播放。旧按钮内直接 playSound('ui_click') 与公共点击处理按同一次事件去重，没有时间阈值吞掉快速独立点击。

位置：“音效与音乐 → 按钮点击音效”，可开关并调节独立音量；上传/试听/还原使用原“基础交互音效 → 按钮点选”。点击音量再经过原音效与主音量链路。自定义按钮声只有一个在播实例，下一次点击停止前一个；页面隐藏或关闭点击音时清理。

全部 41 个活动自定义音效槽：11 个基础/抽签槽、4 个公共道具事件、26 个独立道具槽。5 个旧通用道具音效已由 26 个独立槽取代，原文件与导入兼容保留，不重新叠加。roll_tick 为明确标注的备用槽；默认 roll_loop 试听播放刻度示例，实际抽签继续使用原连续循环缓冲。

音频上传捕获槽位 ID，避免异步读文件串槽；解码成功再更新内存，IndexedDB 事务完成才提示已保存。失败显示未保存，保留磁盘上的原记录。损坏文件不覆盖原解码资源。

## 课堂行为与跳过入口一致性

“共产主义模式”和“跨局保留 All In”采用同一设置卡片组件：两列等高、标题及说明字号统一、同一 52×28 开关，保留原 ID、事件与保存行为。开关支持键盘 Space 与可见焦点。

抽中揭晓文案改为“就是你”，移除全角感叹号。启动、结算庆祝和课堂全屏反馈三个跳过按钮统一固定在页面右下角；按钮作为动画表面的兄弟节点，避免跟随中心内容变换而偏移。跳过只结束动画，不改变保存、抽取或赋分结果。

## 同一操作的多个候选音效

全部 41 个活动操作槽支持“追加音效”，可一次选择多个文件。原“上传”替换主音效，多选的其余文件成为候选；“追加音效”保留主音效并全部追加。每次操作从主音效及候选中等概率选择一个，允许连续两次选到同一个；没有上传时沿用原合成音。抽取循环声在一次抽取开始时选一个，循环中不反复切歌。

候选管理显示文件名并可逐项移除；“还原”清除该槽的主音效和全部候选，事务成功后才更新界面。播放采用独立 crypto 随机源，不消耗比赛和抽取使用的 Math.random 序列。新增候选与原资源共同使用原声音/主音量链路及按钮点击单声部规则。

候选保存在原 IndexedDB sounds 表，键为 `fx_<操作>::variant::<UUID>`，主音效键保持 `fx_<操作>`。每条记录保留 `arrayBuffer`，增加可选 name；不升级数据库版本。原音频 BIN 导出/导入可完整往返候选及名称，旧 BIN 不含 name 时使用降级名称。普通课堂 JSON 备份仍不包含音频二进制，请另行导出音频包。

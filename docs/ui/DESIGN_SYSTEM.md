# 桌面 UI 设计系统 · V2.19.0

## 范围与基准

源码起点：`378f2d23d180802171a8e7d237fe1fb631ee3318`（V2.18.15），不是用 V2.18.13 覆盖最新代码。工作分支 `feat/desktop-ui-system`。保留原始单文件及既有修复分支；所有测试使用隔离 Chromium 上下文和合成数据。

主目标 1920×1080，最低 1366×768，大屏 2560×1440。仅维护桌面。窗口浏览器缩放与应用内 CSS 缩放是两种不同机制，测试报告分别记录。不得将本轮程序缩放结果声称为浏览器工具栏缩放结果。

## 样式所有权

- `src/ui/desktop.css`：新页面组件、字体/间距/圆角/阴影/动效/窗口等级变量；`.ui-*` 命名空间。
- `src/style/02.css`：现有青绿珊瑚色彩变量、导航/底栏/旧窗口主题的原位置修订。
- `src/style/15.css`：现有可读性与设置滚动规则；已删除旧的四页设置面板互斥规则。
- 其余旧样式按原有归属保留，不批量移除特殊状态和动画。只移除已退出模板的旧欢迎页容器选择器，详见 `artifacts/desktop-ui/removed-css-selectors.json`。
- 新组件不使用 `!important`。既有主题中的 `!important` 尚未整体迁移，属于已记录技术债，不能声称已经清零。

## 导航、容器及工具栏

五个页面固定为欢迎、比赛、历史、档案、设置。导航使用内嵌 SVG 与文本，当前页同时设置 `aria-selected` 和 `aria-current`。顶栏固定单行，长组名在统计区省略，不挤压导航。

比赛栏保留 67px 原高度，仅比赛页显示。切出比赛设置 `hidden`、`inert` 和隐藏样式，捕获阶段拦截隐藏比赛栏的陈旧按钮事件。UI 屏蔽不替代业务校验。原业务 API 仍可由测试调用。

答题按钮位于左侧；道具/举手/点名/撤销位于右侧；低频管理、视图缩放、帮助、成员搜索与解锁进入“管理与视图”菜单。所有按钮移动原节点，不复制事件入口。正式结算维持原确认与保存规则。

新页面使用一致的内容边距、标题、面板、空状态和提示。设置只有右侧内容滚动；分类导航位置稳定。保留全部原设置控件 ID、事件处理及存储键，兼容安装器检查 `uiSettingsShell` 防止重复重建。

## 比赛页布局保护

不得改变 `groupList` 网格、卡片外部尺寸/最小宽度/纵向间距、比赛容器边距、垫片/排名区空间、单列/多列与缩放规则、批量栏位置。无右侧常驻栏。

合成配置 `BATTLE_14_GROUPS_BASELINE`：14 组、多列、垫片启用且 120px；1366×768 使用应用缩放 0.8，1920×1080 与 2560×1440 使用 1.0。含长名称、大积分、负积分、不同组色、主要/次要队列、持续状态、答案与 All In。用户实际课堂视口/缩放/垫片配置尚未读取，不能声称复现了用户的真实配置。

逐卡 DOM 比较见 `artifacts/desktop-ui/battle-14-comparison.json`。原截图在 `artifacts/ui-baseline/battle-14-*.png`，修改后在 `artifacts/desktop-ui/battle-14-*.png`。验收要求相同配置下全部 14 组在底栏上方、几何差异不超过 1px、页面不增加滚动要求。原版本身已有的页面底部留白/滚动高度不伪装成零滚动。

## 欢迎页与每日内容

日期/问候和入口位于顶部；小组栏为主要信息。真实组数据读自 `state.groups`，排名按现有积分顺序，主要道具读自库存；遮蔽状态沿用 `blooperUntil`。卡片点击原小组窗口。支持仅溢出时滚动、滚轮/触控板和左右按钮；少量组居中，不自动滚动。

`src/ui/model.js` 提供离线示例、自然日索引、稳定轮换和题库校验。以本地日历日期构造 UTC 日序号，避免夏令时造成一天不足/超过 24 小时的问题。相同日期不使用随机数选内容。

政治卡片均标为教学示例并给出宪法条款依据，不宣称教材原文。教师可导入其他学科，并通过分类开关/学科选择控制展示。未提供当前班级名称字段时不虚构班级名。挑战答案与解析来自同一对象，不调用计分或历史接口。没有对应学科内容时明确显示空状态。

题库格式与规则见 `docs/DATA_SCHEMA.md` UI 扩展部分。道具小知识直接读取最终 `ITEM_DEFS`，不另建效果副本。荣誉从实际封神榜读取。

## 历史与档案

历史采用操作前快照时间轴。差异比较“此操作前快照 → 下一次操作前快照/当前状态”，说明两快照间可能含未记录操作。积分、序位、道具、实际持续字段和回合状态均以真实快照计算。最近快照不冒充当前状态。

查看与恢复分离。恢复前展示目标时间、描述、影响字段和后续历史丢弃范围，确认后调用原 `revertToHistory`；锁定检查和恢复语义不变。

档案概览只从归档计算届数、冠军、最高分和最近时间。搜索/排序不改变原存储顺序，导出/删除使用原记录索引。领奖台和表格沿用归档名次；同分不擅自重新排名。旧字段缺失显示“未记录”，不生成统计。提供现有 CSV 和原始 JSON 导出。

## 弹窗、点名与道具表现

普通/危险确认使用原主题 Promise 弹窗；输入窗 480px；名单/搜索等 680px；道具/点名等大型功能窗保留独立布局；结算使用独立全屏演出。统一生命周期管理包含焦点进入、Tab 环绕、嵌套 Escape、关闭后恢复焦点、重复打开及页面切换关闭。未替换各窗原有关闭业务。

点名保留原先选出真实结果的业务流程，只重排模式、结果、统计/历史与赋分区。结果无效或抽取中时禁用赋分，实际赋分仍由原业务接口校验。切模式沿用原清空结果机制，不能给旧目标加分。

视觉事件为 `godpower:visual` 的 `CustomEvent`，包含 ITEM_DRAW_START、ITEM_DRAW_REVEAL、ITEM_USE_START、ITEM_HIT、ITEM_DEFENDED、ITEM_EFFECT_APPLIED、ITEM_EFFECT_EXPIRED、ITEM_QUEUE_PROMOTED。事件来自现有表现调用或状态差异，不决定结果。新动画使用可取消 Web Animations；旧视觉节点在切页/关闭时清理，不移除持续状态业务字段。所有自定义图像保持 `object-fit:contain`。

最终结算 UI 显示保存中/失败信息；仅原命令返回成功后呈现庆祝。取消排队确认会阻止尚未启动的命令。跳过演出调用原关闭函数，不跳过保存或改变归档数据。

Toast 使用 `popover="manual"` 进入浏览器 top layer，角色为 status、礼貌朗读，不拦截鼠标；不支持时使用最高常规层级回退。生命周期仍为 3800ms，不因页面切换被移除。

## 发布与证据

`npm ci && npm run verify` 包括语法/资源完整性、纯模型、业务回归及桌面 UI。`npm run test:ui` 可单独执行 UI；测试隔离存储，不加载用户真实课堂文件。

构建仍将资源、CSS、脚本内联到 `dist/godpower.html` 和 `dist/index.html`。不增加运行时 CDN/API。Sites 复用 `.openai/hosting.json` 绑定，保持私有受众，推送精确提交后打包部署。禁止记录 Git 临时凭据。

本轮禁止任何 CircleCI 操作；远端 CI 不自动触发，保留现有手动 GitHub Actions。

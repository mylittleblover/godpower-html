# 首页反馈与窗口退出规范

基线：`3f63199f04f9fba046823e72ddbc4a1b8ab2c517`。桌面 UI 专项，保留比赛几何、计分、道具、历史及存档规则。

## 首页

- 小组巡航以 requestAnimationFrame 按时间推进，速度 28 CSS px/s；每帧间隔上限 50ms，恢复后台不追赶时间。关闭吸附，避免逐卡停顿。
- 仅当原始卡片宽度超过容器时建立一份循环副本。副本不增加小组数据、无 data-group、无键盘 Tab 入口、对辅助技术隐藏；点击沿用原小组详情入口。副本总量最多等于真实小组数量。每次数据变化更新副本。
- 鼠标悬停、键盘聚焦和拖动暂停；离开后保留短暂阅读间隔。手动箭头操作暂缓 5 秒。离开首页、页面隐藏、关闭动画或系统减少动态效果时停止帧循环。
- 新模式默认开启。旧界面偏好没有 groupCruiseVersion=2 时启用新默认；新模式下手动关闭会连同版本标记持久化，以后不会强制开启。比赛存储键不变。
- 推荐内容统一为等宽等高的两列四卡布局，取消大小卡、跨列和跨行。通过道具图标与标题并排、挑战选项两列排列、操作区靠底减少内部留白；展开后同排仍对齐。关闭分类后自动收拢，单卡占满一行。保留每日稳定轮换、真实道具资料和真实归档。
- 四项 KPI 继承同一字号；大整数完整换行并保留 title，不单独缩小积分字号。

## 百科

旧 `#aboutMain` 标题样式直接读取语义变量 `--window-head-text` 和 `--window-head-subtext`，修复高优先级旧选择器与青绿标题底色冲突的根因。不新增更高优先级覆盖。

## 窗口退出

`showClassroomWindow` / `hideClassroomWindow` 是既有窗口函数调用的 UI 适配器；`DesktopUI.dismissWindow` 是唯一退出动画实现。无同名业务函数覆盖。

- 完整动效：280ms / 动画速度，位移从 0 到向下 64px，同时透明度降至 0、缩放至 .97，缓动 `cubic-bezier(.55,.05,.85,.35)`。
- 简洁动效：120ms、向下 10px。关闭动效、关闭页面动效或系统减少动态效果时立即关闭。
- 关闭开始后窗口 inert，阻止重复点击；原业务清理和确认结果仍由原命令立即执行，视觉退出不会决定结果。
- 动画结束再隐藏/移除窗口，由原弹窗栈归还焦点、移除遮罩层级。动画取消也完成清理。
- 重新打开同一窗口取消旧关闭，不允许旧回调隐藏新窗口。动态确认窗口被替换时先完成旧退出，避免同 ID 重复。
- 保留原窗口打开、取消、确认及 Escape 行为。对原有“立即不可见”测试改为等待真实退出完成，同时新增退出关键帧、禁用交互、重复开关和清理断言。

复现命令：`npm run build && npm run check && npm test && node tests/e2e/welcome-feedback.mjs`。更多回归和真实结果见本轮验收报告。

# 全局功能界面视觉规范

基线：`f2b39e64742f5fa546283ce900c3c4202962bb30`，实际版本 V2.19.0。独立分支 `feat/desktop-visual-unification`。

## 所有权

`src/ui/application-surfaces.css` 统一顶栏、底栏、比赛卡片表面、功能窗口、历史与档案页。首页保留 `welcome-v2.css`，设置页保留 `desktop.css`。模板和 manifest 同步内联新样式；发行包无运行时网络依赖。

旧样式中必要的几何规则继续保留。原有高优先级外观声明改为读取组件变量，未增加 `!important` 或同名函数覆盖。`--control-*`、`--window-*`、`--chrome-*` 和 `--battle-card-*` 提供兼容桥；后续迁移几何规则时逐组件移除旧声明，不能直接删除仍控制特殊状态的规则。

## 视觉与尺寸

- 使用首页青绿标题面板、白色圆角表面、浅绿色控件与珊瑚强调色；危险操作仍为危险色。
- 顶栏仍为 59px，标签有 SVG、文字、选中底线与浅绿选中背景。底栏仍为 67px，仅在比赛页显示。
- 小组卡片仅调整圆角、阴影、文字字重、颜色与选中轮廓。禁止修改排列、宽高、内外边距、列数、垫片与缩放；道具特效继续由原效果系统控制。
- 窗口共用 20px 圆角与浮层阴影。表单保留紧凑结构；小组、规则百科和点名保留导航/内容分区；结算仍为独立演出。
- 历史与档案使用与设置页一致的青绿标题区。依据应用缩放换算的视口高度约束页面；正文独立滚动，避免展开快照撑高整页。
- 档案搜索独立图标输入框、排序标签、44px 控件、记录数胶囊。空状态说明与进入比赛按钮保持 24px 间距，搜索、排序和进入比赛行为不变。

## 动效

启动时顶栏五个标签逐个从上向下进入，完整模式位移 -22px → 0，340ms，间隔75ms，速度沿用偏好。简洁模式位移-5px，180ms，间隔25ms。它们加入 `WelcomeV2` 现有动画集合，与品牌 FLIP 一起在跳过、Escape、切页、隐藏、缩放/视口变化时清理；关闭动效不会制造隐藏标签。

普通窗口通过 `DesktopUI.animate` 从下方42px、缩放0.97飞入，420ms，使用 `cubic-bezier(.16,1,.3,1)` 非线性缓动；简洁模式为8px/160ms；关闭、重复打开和切页沿用焦点栈及取消机制。历史/档案标题先出现，前8个节点错峰进入；只改变透明度与独立 translate，不影响数据结果。冠军揭晓保留既有编排。

## 验证

`npm run test:surfaces` 执行新专项；`tests/e2e/desktop-modal-matrix.mjs` 执行11个重要窗口 × 3分辨率 × 3档应用缩放；14组对比必须显式传入本轮基线 SHA。测试暂停实际 WAAPI 标签动画检查关键帧/错峰时序，并通过 Escape 验证取消，未将静态截图当作动画测试。

结果与限制见 `docs/reports/APPLICATION_SURFACES_ACCEPTANCE.md`。浏览器工具栏原生缩放不能用应用 CSS zoom 冒充。保持 Chromium-only，不操作 CircleCI，不写真实课堂数据。

## 统一关闭与展开

每个现役功能窗口在原模态生命周期内获得一个圆形34px叉号关闭入口，复用小组管理的外观；重复的“关闭/退出”入口隐藏，表单取消、跳过庆祝等有含义的操作保留原动作。关闭仍调用原关闭函数，不绕过异步取消或数据保存。

所有原生 details 的鼠标和键盘展开由同一事件委托处理，用真实展开/收起高度做280ms非线性动画。连续点击反转目标，切页、窗口关闭或减少动态效果会稳定到目标开合状态，恢复overflow；底栏浮动管理菜单保持自己的弹出结构。

## SVG老虎机与拉杆

点名中央使用自包含SVG机身和独立HTML滚轮，右侧原生button作为可键盘操作的拉杆。原按钮ID、三模式和原随机结果保留。停机立即完成原有选择及防重复记账，UI使用循环的真实候选名称做1000ms减速，最终行显示原结果。表现不调用业务随机数。

减速时暂缓展示结果及UI奖励按钮，结束后启用真实目标；关闭、换模式、切页或关闭动效会清理滚轮覆盖层。没有延后、重算或伪造业务结果，也不改变音频与奖励计算。

## 口令与错误提示

口令窗使用同一表面、圆形叉号和飞入动画。模态的视觉层级由现有焦点栈按打开顺序分配；原口令/主题窗固定高层级改为读同一变量，防止错误口令提示被口令窗遮住。关闭后恢复原层级和输入焦点；取消仍保持锁定，正确口令才解锁。它依旧只是本地误操作保护。

减速滚轮复用原学生格式化函数，候选与最终行都保留所属小组颜色的学号；主循环与最终结果也沿用该格式化。滚轮窗口收紧到机身高度的26%，未改变成员字符串或抽取池。

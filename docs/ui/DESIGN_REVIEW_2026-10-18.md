# Refactoring UI 与 Emil 设计/动画整改

基线68dc705；分支fix/ui-design-motion-audit。原生HTML/CSS/WAAPI，无Tailwind/组件库，无独立深色主题。本次复用既有青绿/珊瑚设计变量，不引入联网依赖，不改变业务与14组卡片几何。

按层级→间距→字体→颜色→层次→图像→细节顺序检查。34张1920基线截图包含五页、八个设置分类、18个功能/子状态窗口及三类空状态。详见artifacts/design-review/before/inventory.json。

|编号|维度/优先级|位置|规则|实际问题|修复|
|---|---|---|---|---|---|
|DR-01|层级/布局 P1|首页排名|3.3、3.6|14组排名658px高，把小组栏推到下方|限高可聚焦滚动，保留全部排名并提示滚动|
|DR-02|对比度 P0（设计分级）|首页辅助文字/表头/元数据、窗口提示|5.6|gp-panel-title small实测2.29:1；surface-muted/白4.11:1|用现有深青绿文字变量，最小辅助字号复用12px|
|DR-03|对齐 P1|批量学生赋分筛选|3.6|14组时第二列左边界不同，组标签单独换行|固定标签列+弹性内容列，保留学号颜色|

|DR-05|中断 HIGH|统一窗口关闭|Emil Interruptibility|30ms关闭时opacity从0.38突跳到1，translate从26px跳0|从当前计算视觉状态开始退出，保留280ms向下非线性路径|
|DR-06|衔接 MEDIUM|窗口遮罩|Emil Cohesion|内容淡出但遮罩最后一帧突然消失|同周期遮罩opacity淡出，原生dialog针对::backdrop，关闭/重开均清理|

业务道具动画长时长为用户明确要求，保留1700ms效果及抽取尾部淡出；不因通用300ms建议削短。窗口入场420ms为现有课堂投影设计选择；统一退出保留280ms，只改为既有motion-ease语义的Emil ease-out。用户明确要求所有页面和窗口动画，保留键盘下既有页面/窗口过渡。测试只使用桌面Chromium，不做手机专属布局，不执行CircleCI。

第二遍细节：搜索空状态的旧灰字和批量学生条目的小组说明也有低对比度；修复原样式所有者，长组名限制在条目内并保留完整title。学生学号仍使用原小组颜色，不改编号或成员解析。

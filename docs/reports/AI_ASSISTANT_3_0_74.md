# 3.0.74 AI课堂助手：首期验收

## 实际交付

新增一级AI页及设置中的AI助手分类，保留现有桌面主题、消息入场动效和减少动态效果。默认离线规则助手，明确不冒称大模型；可查询小组积分、导航、准备单组加减分。Electron优先支持OpenCode当前Console/Go及旧Zen/Go兼容地址，另保留OpenAI、DeepSeek、OpenRouter及本机Ollama连接选项。

每次模型请求仅发送本次文字和经勾选授权的匿名G1等编号/积分，不自动发送历史对话、学生、学号、组名或头像。模型动作使用严格白名单，不执行HTML、JS、selector或文件/IPC指令；所有改分先预览，教师点击确认后复用现有ManualScoreCommands和持久化ACK。没有开放道具、删除、导入、归档或自动评分。

提案绑定稳定小组身份、存档ID/代次/修订和页面代次，确认前和真正派发前再校验；重复确认共享一个执行结果。没有更改比赛计分、道具、撤销、存档格式或14组卡片样式。AI只复制必要的保存状态标量和积分，不为读修订号克隆整个课堂档案。

对话和至多100条脱敏操作审计仅保留本次页面会话，可由教师导出；待确认操作不持久化、不在重载后自动执行。每个请求独立发送，本期尚无自动多轮上下文、知识库检索、动态教学工作台或学科Skills，不能称整个AI规划完成。

## 修复过程与复审

- 发现设置面板在DOMContentLoaded监听器间的微任务中挂载过早，导致模型表单未接入；改为在事件完成后挂载一次，保留输入DOM。
- 红灯复现确认与派发之间修订变化仍可执行、取消40个提案后无法继续；补二次校验和有界清理。
- 红灯复现切换模式残留发送授权，修复停止/模式切换重置授权。
- 复审发现异步读取可能在清除后恢复密钥，新增真实异步顺序回归，改为共享读取Promise和串行配置/清除；复审确认已修复。
- 复审发现返回响应时读取最新复选框会给未发送的匿名别名授权，延迟响应浏览器用例先失败（5个提案而非4个）；绑定发送时的共享选择后通过，复审无剩余Critical/Important。
- 新增路由/设置类别后，仅更新明确的完整条目清单断言，保留原不可覆盖路由、唯一ID、样式归属和其余全部校验。

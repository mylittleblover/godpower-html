- 旧教师/课堂组合只按真实assignment转换，未归属课堂保留名单，不按重名合并、不猜测成绩。

- 归档失败不清零；归档成功但新赛季保存失败则持久冻结该赛季，可刷新后继续初始化，不重复归档。

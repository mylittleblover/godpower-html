# 道具积木与首页内容交付记录

日期：2026-10-18。HTML 起点 d2b1bc9；独立分支 feat/item-building-blocks。Electron 桌面版本保持 3.0.0。

## 实现

- `src/items/catalog.js`：26 个独立道具蓝图，显式组合目标、效果、次数消耗、持续状态和超车兼容标记。
- `src/items/operation.js`：目标选择、效果、库存消耗、统计/续用及反馈积木；公共 `useItem` 不再调用 `legacyUseItem` 覆盖链。
- `src/items/draw.js`：首轮举手专属池、榜首喇叭概率、防重复、权重与冷却提交；与使用流程隔离。
- `src/core/item-module-model.js`：纯配置与校验；`item-modules.js` 负责本机存储和 UI 通知。
- 道具与图标设置新增模块工作台。每种道具分别配置抽取开关、权重倍率、新获得次数、主动使用开关、适用的积分倍率、发动动画；带导入、导出、单项及全体重置。保留原图标维护界面和原自定义音效。
- 持续占槽的巨大蘑菇/强力蘑菇，以及偷取道具的幽灵，次数固定为原值；没有提供无效重复次数控件。非积分类型也不显示积分倍率控件。关闭主动使用不剥夺已持有物品的被动防御。
- 首页百科入口直达实际百科；知识点可下一轮；答对后可下一题，两者游标相互独立，不产生比赛积分。
- 欢迎页设置新增知识点/题目的添加、编辑、删除、JSON 文件导入及导出，保留高级 JSON 编辑；重复 ID、非法选项、损坏输入与存储失败不覆盖原题库。
- 小组序号徽章在饱和配色上优先白字，必要时仅加深徽章底色以达到 4.5:1；不修改保存的组色、积分颜色、卡片尺寸和排列。

## 兼容边界

旧 `legacyUseItem` 及旧抽取包装定义仍保留作对照，没有按版本号批量删除；公共入口已切到新的道具积木执行器。持续回合结算、特殊被动防御、音频底层仍复用原规则服务，避免把模块化扩大成无证据的内核重写。

保留一个已存在的兼容行为：幽灵无法偷走正在占槽的巨大蘑菇时，原实现会提供三题保护但不消耗幽灵、使用统计不增加。本次保持一致，未来如调整需单独确认产品规则。

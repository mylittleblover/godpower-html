# 3.0.71 离线头像预设开发版

## 已实施

设置 → 学生与小组管理 → 点击个人或小组头像，可搜索、按分类选择预设、上传照片或清除头像。仍通过现有头像规范化、资源哈希、存档事务保存；未建立第二份名单或头像库。每页最多24项，全部115张160px WebP约392KB，完全内嵌，不依赖联网。

素材：官方大乱斗角色列表84项、近代政治人物6项、现代政治人物9项、花草8项、岩石8项。包含习近平、胡锦涛、邓小平、毛泽东、江泽民、周恩来、林彪、王洪文、赵紫阳，以及马力欧、火狐、卡比、皮卡丘等。84是官方页面可提取的条目数，不宣称包含全部变体/换装。部分角色暂用官方英文名。逐项来源、原图/缩略图SHA-256及许可说明在docs/AVATAR_PRESET_SOURCES.json；官方宣传角色图仍受各权利人版权保护，未冒称自由许可。重采集脚本scripts/build-avatar-presets.py，日常构建不联网。

## UI及生命周期

遵循现有青绿/红色主题tokens，使用正确的--ui-panel；截图暴露旧草稿透明且靠左上角，已用真实浏览器复现并补居中/不透明断言后修复。原图在artifacts/avatar-presets/before-layout.png，修复后chooser.png。原生dialog提供焦点/键盘和顶层隔离；内层surface复用共享关闭动画owner，打开自下向上、关闭向下，支持减少动态效果与动画中断。

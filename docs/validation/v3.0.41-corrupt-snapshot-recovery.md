# V3.0.41 损坏主快照恢复验收

## 改动

- 损坏 `godpower_state_v2` 时增加只读恢复面板，不会静默从旧版回退或覆盖主键。
- 可将原始主键内容下载为 UTF-8 文本；扫描范围为 `godpower_state_v1`、旧版分散存储镜像和先前保留副本。
- 每个候选先显示组数、积分合计及与当前页面内存状态的差异；确认后调用既有 `importClassroomData`，由其保留损坏原文并校验、保存、回滚。
- 点名池、冷却序号、点名/举手历史及历史快照加入嵌套格式、长度和递归深度限制。

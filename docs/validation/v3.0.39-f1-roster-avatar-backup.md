# V3.0.39 名单与头像联合备份验收

日期：2026-10-20  
仓库：`mylittleblover/godpower-html`  
分支：`feat/v3-foundation-sp01-sp02`  
范围：F1 名单工作区和头像资源组合导出/恢复；比赛规则与正式课堂状态不变。

## 实现

- “导出名单”生成 `godpower-classroom-roster-backup` schema 1 JSON，包含已保存的 roster 和其全部头像二进制、元数据。
- 单个头像上限 2 MiB、所有头像解码后上限 50 MiB、输入包上限 70 MiB；导出拒绝未保存的名单草稿或缺失头像资源。
- 导入保留旧版纯 roster JSON 兼容；组合包需要引用完整、头像属于包内课堂、MIME/扩展名/签名和 SHA-256 全部匹配。
- 已存在的相同资源复用；资源 ID 已被其他内容占用时新建 ID 并改写导入名单引用，不覆盖已有 Blob。
- 先提交并验证 IndexedDB 头像批次，再 CAS 写入 roster。若名单存储失败，回滚本次新建资源；回滚失败会将错误展示给用户。
- 教学资源库通用导入大小仍为 20 MiB/文件；名单头像组合备份使用头像专属 2 MiB 限制。

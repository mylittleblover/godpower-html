# V3.0.48 名单头像展示验收

环境：Chromium，1920×1080，1x；隔离浏览器上下文与临时名单/资源数据。未覆盖真实课堂数据。

## 行为

- 名单学生头像经本地教学资源库的资源 ID 解析，不将头像字节写入课堂快照或 roster JSON。
- 比赛小组卡片将可用成员头像放入原彩色编号方块区域，最多显示四个不同头像，组号移至图像下方；没有头像仍显示原编号。
- 点名老虎机姓名左侧显示已选学生头像；小组抽取使用该组成员头像组合。结果由原点名业务决定，头像仅呈现已选结果。
- 停止抽选后的全屏揭晓显示放大的学生头像或小组头像；没有头像时只显示文字。
- Electron 消息仅携带经大小限制的 WebP 缩略图，窗口 renderer 再校验 data URL 格式。

## 限制

当前没有独立的小组头像数据模型；小组头像由其关联学生的头像拼贴构成。头像上传/引用偏好仍按活动课堂上下文展示，profile 隔离和孤立资源清理仍在维护清单中。头像获取失败不会阻止点名或比赛操作。

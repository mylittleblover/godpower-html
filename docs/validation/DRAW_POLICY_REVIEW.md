# 连续抽取权重裁定

旧224次正式命令基线已完成，28道具合法效果和抽取类别已独立核对。现移除原前3/中游/后30%硬分区，采用旧20组第2/10/20名权重作为三个形状锚点；每个非例外项目至少0.5，按相对名次smoothstep插值。追赶组star/mega/bullet/lightning/power/spiny另乘1+0.5×相对后位+1.5×正向分差系数，分差系数=clamp(log2(榜首/max(1,本组))/2,0,1)。不会以负分/负比分比率颠倒概率。

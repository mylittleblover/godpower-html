基线：fc81d1f（3.0.65 样式语义化检查点），分支refactor/semantic-style-governance。保持当前28道具、积分/归档/数据、现代青绿/马克思主题、动画与14组布局；没有开始性能优化。

## 清理结果

- 39条同条件、同属性的旧覆盖声明；8条被同规则inset简写重置的定位声明。
- 301条在固定body.modern-flat主题契约下被更高优先级/特异性的现行声明遮盖的旧基础声明。根HTML原本就带modern-flat，没有为了删除规则改变默认主题；组件预览复制相同body类。共享原生tooltip样式不使用这一删除假设。
- 199个已退役界面的选择器分支及1个无生产入口的旧ID分支，另将一处等特异性的:is旧分支收敛为当前标题。删除111个已无样式职责的类名索引，保留13个运行时动态类（10种光环、2种滚动分数、头像count-1）。
- 删除11个无调用关键帧；清理空规则和空条件范围，保留keyframes/layer等具有自身语义的at-rule。
- 两份轮盘定位补丁合并为draw-layout.css；旧音效工具栏、旧道具规则说明框、旧提示文案3份样式文件整份退役。业务导入导出/规则接口未删除。
- 18个CSS文件按职责归入唯一src/styles根，src/ui不再有CSS；styles/ui平行目录也移除。JS数据/命令目录不因样式迁移改变。

以上都有按源位置、条件、优先级、替代声明/renderer、内容哈希及顺序记录的机器证据，见artifacts/css-consolidation-3.0.66。不会因为版本号、important数量或没有完整字符串就直接删除代码。

## 变更

通用教学资源库的删除按钮在确认前检查 roster；发现任何学生仍引用该 `resourceId` 时，显示错误并保留资源。名单无效/不可读时也拒绝删除。用户完成名单中的头像清除后，仍可以走原确认流程删除资源。确认后再次检查名单，缩小用户确认期间引用发生变化的窗口。本修改不自动回收任何头像或教学资源。

## 限制

名单 localStorage 与资源 IndexedDB 无法组成一个物理数据库事务。确认后再次读取名单可保护正常单窗口工作流，但不同浏览器窗口同时写名单/删除资源仍不存在跨库锁。资源没有自动清理；删除共享引用前仍要求教师显式解除名单头像。Windows 原生与 `file://` 本轮未测；CircleCI 未运行。

## 本阶段边界

布局模型提供有界的12列网格、布局/卡片实例版本校验、配置 JSON 安全边界、重叠检测、唯一/多实例规则、确定性冲突挤推、草稿撤销/重做及保存/取消。模型不读取课堂状态，不访问 DOM，也没有写入任何用户布局偏好。当前欢迎页外观与行为没有变化。下一步须先实现隔离的布局仓储与旧首页迁移预览，再接只读渲染和编辑器，不能把本阶段称为“可自定义主页已完成”。

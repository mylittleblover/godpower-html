## 实际删除

### JS

移除24个失效节点（格式化前24,861字节）：globalItemDraw/handDrawItem的旧函数、覆盖赋值、捕获别名、已被最终流程取代的包装器，以及无剩余调用的辅助函数。它们在用户操作前已被最后的抽取流程完全覆盖；前置音效和计数行为已由当前流程直接完成。

两个抽取入口现在各只有一个具名定义，位于runtime/items/draw-flow.js。现行1500ms滚动、900ms结果停留、620ms淡出、奖池权重、去重、轮次冷却、音效及举手事务代码均保留。没有根据版本号删除仍有作用的其他包装器。

### CSS

移除33条较早声明（原文本861字节），每条都有更晚的无条件、同选择器、同属性、同值与优先级声明。每条见css-removals.json及对应证明测试。保留媒体条件、supports、关键帧、特殊状态、回退和未知可达规则；没有添加!important补丁。

格式化使更多等价CSS被词法统计识别为重复，因此静态重复计数可能上升；该计数不是删除依据，也不声称全部历史CSS都已无重复。

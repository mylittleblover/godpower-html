## 变更

公开 `useItem` 命令在道具真实生效后提交 `ITEM_USED` 领域事件，数据包括稳定小组 UID、赛季 ID、道具键、实例 ID 和使用次数前后值。事件经课堂命令持久化后写入成就账本；被冰冻取消、未消耗且未生效的尝试不发事件。撤销恢复操作前课堂快照并回退该事实。没有改变道具规则、分数算法或存档 Schema。

## 收录与预览

91类现行组件/结构样例：基础控件、页面导航、11类主页卡片、比赛/队列、课堂工具、九类设置、资源/题库、已知功能窗口、反馈及26种道具。另由全部发行CSS生成823个样式类、266个变量和108个动效定义的完整索引；索引包括仍保留的兼容定义，不宣称每个定义都正在可见界面使用。

可搜索组件/来源、查看当前节点、切换只读预览主题、展开内部details并重播/刷新样例。优先克隆当前真实DOM；未进入相应业务状态的内容明确标为结构样例，不伪造统计，不为展示主动创建比赛或弹窗数据。音视频不启动，画布像素不复制，瞬态动效另有索引。

预览采用封闭Shadow DOM做表现隔离，不是第三方插件沙箱。克隆树inert，删除事件/脚本/嵌入/跳转，密码和文件值清空，资源与CSS外链过滤；不提供命令、存储和原生权限。Electron frame-src none不放宽。打开、退出和焦点复用原窗口生命周期。

## 样式冲突处理

- 保留现行扁平tokens，旧v292与原生偏好开关统一为54×30外框（52×28内容区）、相同轨道/边框与24px滑动位移。
- 去除旧渐变和后续重复important覆盖，保留白色滑块。
- 去除双重焦点框，保留单个可见轨道焦点框。
- 真实复现禁用态通用opacity规则暴露透明输入，修复为仅轨道/原生输入变淡，兼容输入保持opacity0。初次失败及修复后证据保留。
- 预览曾因CSSOM cssText往返丢失var背景简写而落入旧蓝色按钮；改为保留原声明，仅在选择器上下文将root映射为host，单测覆盖字符串/注释/变量值，真实截图验证红色主题按钮颜色正确。没有用预览专属覆盖色掩盖问题。

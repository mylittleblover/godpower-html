# M7：无插件过渡版 AI 课堂助手

基线 HTML ee18ba2 / Electron 1a89e33，3.0.73，两个工作区干净。用户已要求继续实施，无需重复设计审批。本阶段承接已批准 M7 Task7.1，不恢复插件平台，不把学科插件/任意动态代码执行混进当前版本。

## 实施与职责

1. `application/ai-tool-gateway.js`：纯依赖注入工具网关，支持脱敏积分只读、固定路由导航、单组加减分提案。提案绑定saveId/generation/revision/viewEpoch及稳定groupUid，教师点击确认后才调用现有手动积分命令；重复确认只执行一次，过期/锁定/忙碌拒绝，审计独立于课堂快照。
2. `ui/ai-chat.js`与`styles/classroom/ai-chat.css`：一级AI页面，对话、离线规则助手、模型连接、一次请求的数据授权、停止、明确差异确认、审计/导出。无模型时明确标为离线规则助手，不伪称模型推理。模型结果只显示文本与经过验证的动作；不执行JS/HTML/selector。
3. `desktop/ai-gateway.cjs`：仅主窗口可用的窄IPC，预定义OpenAI/DeepSeek/OpenRouter/Ollama端点，主进程请求，不放宽CSP。密钥输入即移交并清空，不返回renderer、不写课堂存档/日志；默认仅内存，可选系统加密且拒绝basic_text明文后端。超时、取消、请求大小、响应大小、并发和频率限制；无自动重试收费请求。
4. 云端默认不读取学生/组名/头像，只在本次发送获得明确同意后发送用户文本及可选G1等匿名编号/积分。开发测试只用模拟服务，绝不调用收费模型。
5. 完成后运行单元、真实Chromium1920×1080/1x、单文件/file离线、14组几何、Electron受控IPC/模型模拟服务；记录真实云端/Windows硬件未测试；构建、源码同步、分批提交推送、截图上传。

## 验收边界

不提供自动评分、自动道具/归档/删数据、不接入真实班级名册作为模型上下文、不执行模型代码。正式写入仅单组手动积分，保留原计分、历史和保存语义。动态教学组件、知识检索及学科Skills另列后续任务，不称本阶段实现全部AI-00～AI-09。

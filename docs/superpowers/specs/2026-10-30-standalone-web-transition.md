# 独立网页版过渡设计与实施记录

用户要求：保持插件功能不存在，同时恢复插件迁移后新增的功能，包括可自定义主页；入口由实现者重新安排。此前已授权自主设计与实施，不再逐阶段等待确认。

选择：恢复 V3.0.53 中与插件无关的完整源码，再把卡片、主题和道具入口改为宿主直接拥有。相比继续在 V3.0.26 上逐项重写，这能保留既有事务、迁移、资源校验与兼容性修复。不会同步到 desktop/Electron 仓库。

## 入口

- 顶栏仍为欢迎、比赛、历史、档案、设置。
- 绿色欢迎区以下11种卡片全部内置：首页自定义布局入口管理添加、隐藏、移除、移动、缩放、撤销/重做、保存/取消。
- 学生与小组：本地名单、学生头像、备份恢复、应用名单到比赛、旧文本重建。
- 课程表与教学资源：独立设置分类，显式课堂上下文切换及离线资源库。
- 道具与图标：26种道具流程配置、百科与图标维护。公共与独立道具音效归入音效与音乐。
- 欢迎页内容管理：知识点、题库及其导入导出。主题仍由外观分类管理。
- 数据与安全：保留新版损坏存档保护、恢复、导入及事务可靠性改进。

## 边界

不包含插件安装、权限、启停、第三方清单和运行时。核心页面注册表仅继续为宿主页面导航服务。旧首页卡片的三个官方插件类型ID只作为兼容别名读取，映射为内置卡片；不激活插件，也不清除旧布局原文。

权威比赛数据、名单、课程、资源和主页布局维持各自原有存储键。没有读取真实课堂存档。保留单文件资源、14组布局和既有比赛规则。60成就仍以现有实现为准，本次恢复不表示此前尚未实现的规则已完成。

## 实施顺序

1. 对照旧开发分支恢复非插件源代码与测试。
2. 移除插件发行模块、导航和页面；恢复原生道具/音频入口。
3. 将首页目录改为全部内置卡片，兼容旧类型别名。
4. 分离教学分类并接通分类进入刷新。
5. 运行单元、构建、隔离Chromium 1920×1080 1x和离线测试，更新报告并提交。

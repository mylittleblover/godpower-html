## Test gates

1. Before stage 2, run existing targeted `npm run test:item-modules`, `npm run test:migration`, `npm run test:commands`, `node tests/e2e/round-pipeline.mjs`, and `node tests/e2e/run.mjs` as the legacy oracle; record actual outputs and 14-group artifact.
2. For each item/state extension, generate tests from `ITEM_DEFS` and `ItemBlueprints`; assertions include exact legacy score rounding and current defense precedence, not only “returns true”.
3. For async defenses, resolve the confirm promise both ways, supersede it with a newer command, and verify no stale event/inventory/score/history mutation. Only a confirmed, durable outcome emits the corresponding fact.
4. For random events, inject a deterministic PRNG. Test draw budget/sequence and replay with the same persisted state; no runtime `Math.random` in the domain engine.
5. On all stages, retain normal `npm test`, `npm run check`, `npm run format:check`, core Chromium 1920×1080 1x, 14-group screenshot/DOM check, and HTML resource/hash verification. Do not run CircleCI.
6. Electron regression after each HTML phase: source commit+SHA match, Electron unit and desktop browser suites, secure IPC, one authoritative state and one score owner, then Windows x64 cross-build archive integrity. Windows-native launch is NOT TESTED until a Windows host is available.

## Reversion and data recovery

- Keep each stage in one small commit; never rewrite/push history or modify real user storage during tests.
- New fields must be optional/additive and old snapshot readers must continue accepting absent fields. Do not increase main schema version unless a formal migration and rollback fixture exist.
- The feature flag for random events must default off until all engine and persistence gates pass; turning it off must not delete stored event records or state.
- For a failed migration, preserve the original JSON bytes and IndexedDB source; restore only an isolated test profile. Production rollback must export current state before invoking an older renderer.
- Season settlement is not reversible across a committed archive boundary unless an explicit archived-snapshot restore path exists.

# 现行 UI 组件库（直接实施）

用户已要求连续实施，不新增审批关卡。基于3.0.60清理后结构，纯HTML、既有tokens、经典/马克思两主题，不增加框架、CDN或运行时依赖。

## 结构

入口：设置→外观与界面底部折叠的「界面维护参考」，内部打开组件库窗口。不是新一级导航或日常课堂按钮。

组件库包含：现行组件目录（导航、11类主页卡片、比赛/道具、课堂、设置/资源、全部已知窗口和反馈），完整CSS类/源选择器索引，以及全部设计变量。CSS索引由构建源码生成，不能只人工挑选常见按钮冒充全部覆盖。

预览：优先取当前真实DOM，只读克隆并保持祖先选择器上下文。未进入对应业务状态的组件明确标记结构示例；不为预览创建比赛数据、不自动打开业务弹窗、不执行抽取/结算/导入。不可捕获的瞬态样式通过样式索引访问，不伪称已经产生真实业务状态。

隔离：Electron已有frame-src none，不放宽CSP。采用单一封闭Shadow DOM做表现隔离；不是第三方脚本安全沙箱。只读克隆设为inert，删除事件、脚本/表单动作/嵌入节点/跳转，资源只允许离线data/blob图片，样式复制时过滤外链。保留标题、来源和预览来源说明；不输出密码/文件路径。打开/关闭复用现有非线性动画与焦点栈，退出清空预览树。

样式冲突：现行统一tokens优先。重点统一旧v292轨道与原生偏好开关的尺寸/颜色/禁用/焦点；去除被统一实现替代的渐变及重复覆盖。选择checkbox与布尔switch仍区分语义，不改业务字段/事件。

## 实施与验证

1. 生成全CSS类/选择器与变量元数据，建立可维护的组件定义目录。
2. 实现低调入口、分类/搜索/来源、只读隔离预览与主题预览。
3. 统一已确认冲突的开关，记录被保留的现行样式。
4. 模块完成后集中测试：目录全量覆盖、安全/无状态变动、开关两主题/禁用一致、窗口动画/Escape/焦点、1920×1080截图；保持14组布局。
5. 更新版本、文档并同步Electron及发行物。3.0.60清理证明作为历史检查点保留；新功能有独立测试，不能篡改原清理证明。

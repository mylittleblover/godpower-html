# 道具积木与首页内容系统

用户授权自行设计和实施。本次采用独立的道具配置模型与两条有类型的流水线，不允许导入可执行脚本。

抽取流水线：现有排名/唯一性/冷却资格 → 道具开关与权重倍率 → 既有防重复抽取 → 新库存次数。
运作流水线：公共业务校验 → 主动使用开关 → 独立蓝图和目标/效果积木（分数积木倍率）→ 原防御/次数消耗/事务/历史 → 发动演出。

26 种道具各有独立配置，默认与原行为一致。抽取配置不改变已持有物品；关闭主动使用不改变被动防御。所有修改校验后原子持久化，失败保留原配置。保留复杂防御兼容执行器，避免重写破坏 GP-010 生命周期。

首页百科直达实际百科窗口。题目答对后可下一题；知识点可下一轮，两个游标独立且以自然日内容为起点。题库提供知识点与题目表单编辑、来源、答案与解析以及文件导入导出，保留旧 JSON 格式。

只使用 Chromium 1920×1080、1x；保持离线单文件与 14 组布局。

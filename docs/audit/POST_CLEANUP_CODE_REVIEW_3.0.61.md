### GOV-061-01 / P1：全局道具发放重复累计（DONE）

### GOV-061-02 / P1：撤销后旧抽取异步回调继续写入（DONE）

证据：draw-flow.js捕获原小组对象，但延迟回调写入当前全局state；undo替换groups后，旧回调继续抽取并修改恢复状态的计数。抽取会话也先于历史快照递增。修复：快照前移；为抽取创建单一所有权上下文，逐帧、揭晓与退场回调核对state、groups、season和owner。失效时仅清理本轮节点；不能停止新一轮音效/释放新一轮busy。正常1500ms滚动、900ms停留、620ms淡出保留。

回归实际执行：100ms滚动中撤销、1800ms揭晓后撤销，库存/全局会话统计完整恢复、无残留节点、busy释放；撤销后立即启动新抽取，旧owner不干扰新owner。测试不通过修改概率或降低断言规避问题。证据在artifacts/code-review-3.0.61，before与after均保留。
